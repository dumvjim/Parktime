# ParkTime 5.0 — Multiperfil

Demo PWA: conductor, operador y administración. Tarifas de $30 a $50 MXN/h. Reservas, QR y entradas/salidas compartidas en el mismo navegador mediante localStorage. Sin autenticación, pagos ni sincronización entre dispositivos. Los datos de reservas anteriores conservan su importe original. Publicar en GitHub Pages desde main / (root).
